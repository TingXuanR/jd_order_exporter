# 京东订单/退款工具说明

这份文档用于简单说明 4 个工具的用途和使用方式：

- 订单导出插件
- 退款导出插件
- `merge_jd_orders_with_afs.py`
- `apply_jd_returns_by_year.py`


## 1. 订单导出插件

### 功能说明

订单导出插件用于从京东历史订单页面导出订单数据。

主要功能：

- 按年份抓取京东订单
- 导出为 `CSV` 或 `Excel`
- 可导出商品图片地址
- Excel 可带商品图片预览
- 可按需要下载商品图片
- 导出内容适合后续做统计、筛选和退款核对

导出的订单表通常包含：

- 年份、页码、序号
- 下单时间
- 订单号
- 商品信息
- 商品数量
- 支付金额
- 支付方式
- 订单状态
- 收货人
- 订单详情链接
- 商品图片 URL

### 使用说明

1. 在 Chrome 中加载插件
2. 打开京东历史订单页面
3. 在插件面板中选择导出范围或年份
4. 选择导出格式（CSV / Excel）
5. 如有需要，开启图片相关选项
6. 点击导出

### 适合场景

- 导出多年订单数据
- 获取订单主数据
- 获取商品图片地址
- 生成后续分析用的原始账单文件


## 2. 退款导出插件

### 功能说明

退款导出插件用于从京东售后/退款页面导出售后记录。

当前已知、并且已经实际用于后续脚本处理的核心字段包括：

- 服务单号
- 订单号
- 申请时间
- 商品名称
- 售后类型
- 列表状态
- 退款金额
- 结束时间
- 来源列表页

后续退款脚本只会把下面两类记录视为“有效退款”：

- `售后类型 = 退货`
- `列表状态 = 已完成`

### 使用说明

1. 在 Chrome 中加载插件
2. 打开京东售后/退款列表页面
3. 选择需要抓取的页数或范围
4. 点击导出
5. 得到退款 CSV 文件，供后续脚本使用

### 适合场景

- 导出售后退货记录
- 核对退款金额
- 给后续订单修订脚本提供退款来源数据


## 3. `merge_jd_orders_with_afs.py`

### 功能说明

这个脚本用于把多个年份的订单 Excel 合并成一个总表，并结合退款 CSV 生成退款后的分析版总账。

主要功能：

- 合并 `jd-orders` 目录下的多个年份订单 Excel
- 读取退款 CSV
- 只识别“退货且已完成”的记录
- 生成退款后的 `actualPaymentAmount`
- 增加 `returnStatus`
- 增加 `returnProductInfo`
- 对拆分订单支持“子单退款回卷到父单金额”
- 对 `receiver` 进行脱敏
- 输出适合统计分析的合并版 Excel

注意：

- 这个脚本生成的是**总表**
- 不保留嵌入图片
- 保留图片 URL

### 使用说明

默认运行：

```bash
python3 merge_jd_orders_with_afs.py
```

默认输入：

- 订单目录：`jd-orders/`
- 售后 CSV：`jd-afs-20260513-025834.csv`

默认输出：

- `jd-orders/jd-orders-merged-时间戳.xlsx`

### 适合场景

- 做全量历史订单总表
- 做退款后实际支出统计
- 做透视表、筛选、分析


## 4. `apply_jd_returns_by_year.py`

### 功能说明

这个脚本用于先从退款 CSV 中筛出有效退款记录，再按年份分别生成修订后的订单 Excel。

主要功能：

- 从退款 CSV 中筛出“退货且已完成”的记录
- 先输出一份筛选后的退款 CSV
- 再按年份分别更新订单 Excel
- 增加 `actualPaymentAmount`
- 增加 `returnStatus`
- 增加 `returnProductInfo`
- 子单退款可回卷到父单金额
- `receiver` 脱敏
- 尽量保留原年表中的图片、图片锚点和基本格式

注意：

- 这个脚本生成的是**按年份分别修订后的账单**
- 会尽量保留每年账单里的商品图片
- 更适合“继续在原账单里核对”

### 使用说明

默认运行：

```bash
python3 apply_jd_returns_by_year.py
```

默认输入：

- 订单目录：`jd-orders/`
- 售后 CSV：`jd-afs-20260513-025834.csv`

默认输出：

- 新目录：`jd-orders/jd-returns-by-year-时间戳/`
- 目录内包含：
  - 一份筛选后的退款 CSV
  - 多个按年份修订后的订单 Excel

### 适合场景

- 想按年份继续查看订单
- 想在 Excel 里继续直接看商品图片
- 想核对每年退款后的实际支付金额


## 5. 两个脚本怎么选

### 想要一份总表

用：

`merge_jd_orders_with_afs.py`

特点：

- 一个文件
- 更适合统计分析
- 不保留嵌入图片

### 想保留每年的原账单体验

用：

`apply_jd_returns_by_year.py`

特点：

- 一年一个文件
- 尽量保留图片
- 更适合逐年核对
